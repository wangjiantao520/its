## 一、系统概述

ITS 系统是面向**政务信息化项目的工程报价与维保报价**的专业 Web 工具，主要帮助报价人员：

- **快速创建工程报价单**：基于自施工定额和智能化项目定额，自动计算管理费、利润、规费、税金与总价。
- **快速生成维保报价单**：基于设备维保定额库，支持 AI 识别设备清单、自动匹配设备、测算成本与利润。
- **管理报价资料**：保存草稿、提交审核、审批流转、版本管理、分享链接、导出打印。
- **维护基础数据**：设备定额、自施工工序、智能化项目、人工单价、云数据中心定额库、维保费率、SLA 等。
- **AI 智能助手**：对话式查询定额、计算报价、识别设备、生成报告。

系统有两个角色：

| 角色 | 能做什么 | 登录方式 |
| --- | --- | --- |
| **管理员** | 全部功能，含成员管理、AI 配置、基础数据管理、数据看板、报价审批 | 密码登录（`ADMIN_PASSWORD`） |
| **ITS 成员** | 报价相关功能（工程/维保/设备导入/智能助手/报价资料库），不含管理后台 | 用户名 + 密码登录 |

## 二、登录与角色

### 2.1 进入登录页

打开系统地址，自动显示登录页。

### 2.2 选择入口

登录页提供两个入口卡片：

- **「管理端」**（紫色）：管理员登录入口。
- **「ITS成员端」**（橙色）：成员登录入口。

也可通过 URL 直接直达：`/login?role=admin`（管理端）或 `/login?role=its`（成员端）。

### 2.3 管理员登录

1. 点击「管理端」入口。
2. 在「管理员密码」输入框输入管理员密码（由系统管理员设置）。
3. 点击「登 录」。
4. 登录成功后自动跳转到首页，侧边栏显示**全部 11 个导航项**。

### 2.4 ITS 成员登录

1. 点击「ITS成员端」入口。
2. 输入「用户名」和「密码」。
3. 点击「登 录」。
4. 登录成功后跳转到设备清单导入页，侧边栏显示**成员可见的 6 个导航项**。

> 忘记密码时，请联系管理员在「ITS成员管理」中重置密码。

### 2.5 退出登录

点击侧边栏左下角的「退出登录」按钮，系统清除会话并返回登录页。

## 五、工程报价

**地址**：`/engineering`

**功能**：创建、管理、审批工程报价单，维护工程定额库，查看统计。页面顶部有 **4 个标签页（Tab）**：`新建报价`、`报价列表`、`定额库管理`、`统计看板`。

### 5.1 新建报价（默认 Tab）

#### 步骤一：填写基本信息

- **客户名称**（必填）：报价客户名称。
- **项目名称**（必填）：工程项目名称。
- **联系人**（可选）、**联系电话**（可选）。

#### 步骤二：添加报价明细

有 4 种添加方式，可组合使用：

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| **添加自施工工序** | 下拉选择 | 从自施工定额库选取工序，含单价 |
| **添加智能化项目** | 下拉选择 | 从智能化项目定额库选取项目 |
| **人工天计价**（橙色按钮） | 点击添加 | 按「人工单价档 × 人天」计价，可设单价和数量 |
| **自定义明细**（紫色按钮） | 点击添加 | 自由填写名称/单位/单价/数量 |

明细表格列：操作 / 类型 / 名称 / 单位 / 数量（可编辑）/ 单价 / 小计。每行可删除。

#### 步骤三：设置费率

- **管理费率**：默认 8%。
- **利润率**：默认 10%。
- **规费率**：默认 3%。

#### 步骤四：查看汇总

系统自动计算：定额费合计、管理费、利润、规费、税额（13%）、总价。

#### 步骤五：保存与导出

| 按钮 | 效果 |
| --- | --- |
| **保存草稿** | 保存为草稿状态，可在报价列表中找到并继续编辑 |
| **预览报价单** | 预览格式化报价单 |
| **导出PDF** | 下载 PDF 报价单 |
| **导出Word**（绿色） | 下载 Word 报价单 |

### 5.2 报价列表

#### 搜索与筛选
- **搜索框**：输入项目名称/客户/报价单号，回车搜索。
- **状态筛选**：下拉选择 全部/草稿/已提交/已审批/已驳回。

#### 批量操作
先勾选表格左侧复选框，再使用：
- **批量导出Word** / **批量导出Excel** / **批量导出PDF**。

#### 行操作（每行右侧「···」下拉菜单）

| 操作 | 效果 |
| --- | --- |
| 预览报价单 | 查看格式化报价单 |
| 载入报价单 | 把该报价载入「新建报价」Tab 继续编辑 |
| 对比报价 | 选择另一份报价，A/B 对比差异 |
| 变更状态 | 修改报价状态（草稿/已提交/已审批/已驳回） |
| 分享报价 | 生成分享链接 |
| 分享管理 | 查看/停用已有分享链接 |
| 删除（红色） | 删除该报价（有二次确认） |

#### 对比报价
在弹出的对比对话框中选 A、B 两份报价，系统并排展示各项差异。

#### 分享报价
填写**有效天数**、**访问次数上限**、**备注**，点击创建，得到分享链接；「分享管理」中可查看链接使用情况或停用。

### 5.3 定额库管理

管理**自施工工序**与**智能化项目**两类定额。

- **搜索**：按定额名称/编号/备注搜索。
- **分类筛选**：按分类过滤。
- 顶部统计显示「自施工 N 项 / 智能化 N 项」。

#### 导入定额
- **导入自施工** / **导入智能化**：打开导入对话框，拖拽或选择 `.xlsx/.xls/.csv` 文件导入；编号已存在的记录会自动更新。
- **下载模板**：下拉选择自施工/智能化模板下载（Excel）。

#### 新增 / 编辑 / 删除
- **新增**：打开表单填写，保存后加入定额库。
- 行操作下拉：**编辑**（修改定额）、**删除**（移除定额）。

### 5.4 统计看板

- **总览卡片**：累计报价额、平均报价（含最高/最低）、本月新增单数与金额（含环比）。
- **月度趋势**：近 12 个月报价金额走势图。
- **状态分布**：各状态报价数量占比饼图。
- **金额区间**：不同金额区间的报价柱状图。
- **状态明细表**：各状态的数量/占比/总额/平均。
- **刷新数据** 按钮：手动刷新统计。

## 六、维保报价

**地址**：`/maintenance`

**功能**：创建维保报价、AI 识别设备、管理设备定额库、配置 SLA 与增值服务。页面顶部有 **5 个 Tab**：`新建报价`、`查勘问询`、`设备定额库`、`SLA参数配置`、`增值服务`。

顶部还有两个全局按钮：**导出Excel**、**计算报价**。

> 页面提供「使用完整计算逻辑」开关：新版（完整 65 列计算）/ 旧版（兼容模式）。

### 6.1 新建报价

#### 第一步：选择设备识别方式
- **快速识别**（默认）：上传设备清单文件（xlsx/xls/csv/txt）+ 填写需求描述，点「AI识别」自动提取设备清单；也可点「示例输入」快速填充。
  - 识别结果预览：服务地区、合同年限、年度巡检、到场时间、识别设备、待补充信息、建议。
  - 点击「应用到报价单」把识别结果填入报价。
- **AI对话**：通过对话方式描述需求，由 AI 辅助生成。

#### 第二步：确认基本信息
- 报价日期、客户名称、项目名称。
- **合同年限**：1/2/3 年（2 年 95 折、3 年 9 折）。
- **服务地区**：城区(系数1.0) / 市区县城郊区(1.1) / 乡镇(1.5) / 农村(2.0)。

#### 第三步：添加设备清单
- **设备筛选**：按分类多选（清除/全选），点击设备卡片添加到清单。
- 已选设备表格中，每行可修改：数量、折旧等级、是否在保、是否需要备件、合同年限、使用年限、设备分档，或删除该行。
- 辅助按钮：**价格设置**、**批量编辑**、**历史报价复用**。

#### 第四步：查看报价结果
- 新版显示 **四个地区** 的报价（城区/市区县城郊区/乡镇/农村）。
- **成本测算区**：成本率滑块（40%~80%，默认 65%），实时显示维保报价、成本、利润、利润率、含税总价。

#### 第五步：操作按钮

| 按钮 | 效果 |
| --- | --- |
| 历史报价复用 | 从历史报价选择并载入设备清单 |
| 批量编辑 | 批量修改已选设备的参数 |
| 价格设置 | 逐设备设置自定义单价与费用项；「暂时保存」随时可，或「永久保存（仅管理员）」 |
| 专业导出 | 三选一：标准（Word 报价单）/ 详细（Excel 多 Sheet）/ 汇总（Excel 汇总表） |
| 分享 | 生成分享链接（默认 7 天有效） |
| 保存版本 | 保存当前报价为一个版本快照 |
| 提交审核 | 填写审核意见后提交审核 |
| 保存报价 | 保存到报价记录 |
| 打印 | 调起浏览器打印/存 PDF |
| 导出Word / 导出Excel | 导出报价文档 |

### 6.2 查勘问询

分节的**维保查勘问卷**（设备台账、巡检周期、响应时间等），填写后点「保存」。用于采集项目查勘信息，辅助报价。

### 6.3 设备定额库

展示设备维保定额列表：序号/分类/名称/规格/维保分档/工程师等级/四地区报价/核心维保内容。

- 点击「编辑」可修改设备定额（分类/名称/规格/分档 A-E/工程师等级等）。
- 支持分页浏览。

### 6.4 SLA 参数配置

左侧配置卡，逐项选择：

| 配置项 | 可选值 |
| --- | --- |
| 运维团队经验 | 有(1.2) / 类似(1.0) / 无(0.8) |
| 安全等级 | 一级(0.9) ~ 五级(1.1) |
| 支持方式 | 非现场(0.89) / 现场为主(1.0) / 纯现场(1.1) |
| 故障恢复时间 | ≤4h(1.2) / ≤24h(1.0) / ≤48h(0.9) / ≤72h(0.85) |
| 服务时间 | 5x8 / 7x8 / 7x24 |
| 到场时间 | 2小时 / 8小时 |
| 响应时间 | 10分钟内 / 30分钟内 |

底部显示**当前 SLA 总系数**（各系数乘积），提供「重置默认」按钮。右侧为维保分档 A-E 与工程师单价的说明卡。

### 6.5 增值服务

13 项增值服务多选（如定期巡检 5000、维保报告 3000、系统升级 4000、应急演练 6000、数据备份 3500、专人对接 2000、培训 2500 等），支持计算合计。

## 七、报价管理（综合）

**地址**：`/quotes`（管理员）

**功能**：跨类型（工程/维保/综合）报价的统一管理与审批中心。

### 7.1 筛选

- **搜索框**：输入关键字搜索。
- **日期范围**：起始/结束日期。
- **「筛选」按钮**：应用筛选，含计数徽章。
- **「清除」按钮**：重置筛选。

### 7.2 状态标签页

全部 / 草稿 / 待审核 / 已批准 / 已发送 / 已归档，各带数量。

### 7.3 批量操作（勾选后出现）

| 按钮 | 效果 |
| --- | --- |
| 批量批准 | 一次批准多条待审核报价 |
| 批量导出 | 导出 CSV 文件 |
| 批量归档 | 一次归档多条 |
| 取消选择 | 清除勾选 |

### 7.4 排序

点击表格列头（报价单号/金额/创建日期/更新日期）可排序。

### 7.5 行操作（下拉菜单）

| 操作 | 效果 |
| --- | --- |
| 查看详情 | 打开报价详情页 |
| 编辑 | 打开编辑页（已归档不可编辑） |
| 复制编号 | 复制报价单号 |
| 分享链接 | 生成 7 天有效分享链接并复制 |
| 批准报价 | 待审核状态 → 批准 |
| 发送报价 | 已批准状态 → 发送 |
| 导出PDF | 导出 PDF 报价单 |
| 删除 | 删除报价（已发送不可删） |

### 7.6 状态流转规则

**草稿 →(提交审核) 待审核 →(批准) 已批准 →(发送) 已发送 →(归档) 已归档**

- 待审核可**驳回**回草稿。
- 每次状态变更都会写入审计日志。

## 八、报价详情与编辑

### 8.1 报价详情（`/quotes/[id]`）

**功能**：查看报价单完整信息。

- 顶部按钮：**返回**、**复制编号**、**打印或保存PDF**。
- 展示：项目名、报价单号、状态徽章、客户名称、报价类型（工程/维保）、报价金额、创建人、创建/更新时间。

### 8.2 报价编辑（`/quotes/[id]/edit`）

## 二十一、常见问题与技巧

### Q1：忘记登录密码怎么办？
- 成员：联系管理员在「ITS成员管理」中重置密码。
- 管理员密码：由部署者通过环境变量 `ADMIN_PASSWORD` 管理，无法自行找回，需部署者重置。

### Q2：二级密码是什么？忘了怎么办？
- 二级密码用于**基础数据管理的新增/删除**操作验证，默认 `admin`。
- 可在「基础数据管理 → 二级密码设置」修改。
- 忘记后需数据库管理员直接重置 `system_settings` 表（不建议自行操作）。

### Q3：保存报价时提示"保存报价记录失败"？
- 确认客户名称已填写。
- 确认设备明细有效（设备名称、数量、金额为合法非负数）。
- 若持续失败，联系管理员查看系统日志。

### Q4：AI 助手没有回复或报错？
- 管理员在「AI配置中心 → AI模型配置」点「测试」确认模型连通。
- 确认智能体处于**启用**状态、所需技能处于**启用**状态。
- 确认已配置有效的 AI 模型 API Key。

### Q5：如何把报价发给客户？
- 在报价列表选中报价 → 「分享报价」→ 生成分享链接 → 发给客户。
- 或导出 PDF/Word 后发送。

### Q6：为什么看不到别人的报价？
- ITS 成员只能查看自己的报价；管理员可查看全部（可按用户筛选）。

### Q7：系统参数保存后没生效？
- 「系统参数」Tab 的保存当前为**演示性设置**（仅前端提示，未写入数据库），正式参数以各定额库和配置为准。

### Q8：设备清单导入后不见了？
- 设备导入记录为内存存储，**服务重启后清空**。请在提交审核前保存好数据。

### Q9：报价资料库如何让客户看到？
- 在管理端编辑资料，打开「对用户端可见」开关并保存，客户即可在 `/quote-library` 看到。

### Q10：快捷键
- AI 助手：Enter 发送，Shift+Enter 换行。
- 报价单号、编号均可一键「复制」。
